# @sdkwork/course-pc-console

Domain: course  
Capability: course-console

Canonical PC course **tenant admin** console (courses, categories, sections, lessons). Consumes `@sdkwork/course-backend-sdk` through an IM-wired host port (`configureCourseConsolePcHost`).

Embedded in IM via `@sdkwork/im-console-core` → `bootstrapImCourseConsolePcIntegration`.
